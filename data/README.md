# Spray Window data sources

## Pesticide label rules (`sources/label_rules.csv`)

Six real products, each checked against its EPA-accepted label in the Pesticide Product and Label System (PPLS). The farm grows almonds and pistachios, so crop-specific values (PHI, rates, annual maximums) come from each label's tree-nut section. A value the label does not state is recorded as `not stated on label`. The rules checker then applies a farm-policy default and names it as policy in every check.

## Farm records (synthetic, fictional)

Generated by `scripts/seed-farm.ts` into `sources/*.jsonl` and the `farm` Postgres database:

- `farm_blocks.jsonl`: 5 almond and pistachio blocks (B01–B05) near Fresno, California, each with a nearby sensitive site (school, creek, neighbour).
- `farm_crew.jsonl`: 4 crew with certifications and shift hours.
- `farm_equipment.jsonl`: 4 sprayers and irrigation units.
- `farm_past_applications.jsonl`: 6 past applications and outcomes.

## Weather (Open-Meteo, CC BY 4.0)

`snapshot/weather_forecast.jsonl` holds the 48-hour hourly forecast (latitude 36.77, longitude −119.42) that the recorded live runs planned against. Live runs read Open-Meteo through Zetaris (`weather_views.forecast`); offline runs read this snapshot.
